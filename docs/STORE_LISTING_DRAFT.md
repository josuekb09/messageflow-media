# Store Listing Draft

## App Name

MessageFlow Media

## Short Description

Free church media projection app for sermons, Bible verses, and songs.

## Long Description

MessageFlow Media helps church media teams search and project sermons, Bible verses, and songs during services. It supports second-screen projection so the congregation sees only the projected text while the operator controls the service from the computer. Designed for offline use in church media rooms.

MessageFlow Media is distributed free of charge and is not for sale.
