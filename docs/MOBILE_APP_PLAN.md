# Mobile App Plan

The current MessageFlow Media app is a Windows WPF desktop app. It cannot be uploaded directly to the Google Play Store or Apple App Store.

Future mobile versions should be built separately using one of these options:

- .NET MAUI
- Flutter
- React Native

## Recommended Order

1. Keep the Windows app first.
2. Build an Android tablet version.
3. Build an iPad and iPhone version.

## Mobile Rules

- Use the same name: MessageFlow Media.
- Keep the app free.
- No ads.
- No in-app purchases.
- No paid subscription.
- Consider downloadable or offline content packages only if permissions allow.

## Content

Mobile content should follow the same permission rules as the Windows app. Do not bundle or download content unless the project has permission or another allowed free-use basis.
