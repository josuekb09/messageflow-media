# Microsoft Store Plan

MessageFlow Media is currently a Windows desktop WPF app. The Microsoft Store is the first realistic store target.

## Requirements

- Microsoft developer account and Partner Center access
- App identity and package naming
- Store screenshots
- Store description
- Privacy policy
- Support contact
- Free price selection
- Content and permission notice review

## Packaging Options

Option 1: MSIX packaging.

Option 2: Win32 installer submission, if supported by the current Microsoft Store process at submission time.

## Signing

Code signing will eventually be needed to reduce Windows SmartScreen warnings and improve installation trust.

## Store Rules

- The app must stay free.
- No paid subscription.
- No ads.
- No in-app purchases.
- Do not sell the app or bundled content.
- Include the content attribution and permission notice where appropriate.
