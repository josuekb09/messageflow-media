# MessageFlow Production Ready Checklist

## Included Content

- Brother Branham sermons from Voice of God Recordings, covering 1947-1965.
- King James Version Bible, imported from local CSV.

## Not Included Yet

- Brother Frank sermons or circular letters are not production-imported yet.
- Bible favorites are planned for later.

## Service Use

1. Open MessageFlow.
2. Use Sermons for Brother Branham sermons by title, code, phrase, or paragraph number.
3. Use Bible for references or keywords such as `John 3:16`.
4. Select a result and review it in the preview/live area.
5. Click Project to send it to the projection window.
6. Use Previous and Next for nearby sermon paragraphs or Bible verses.

## Admin-Only Tasks

- Import Bible.
- Manage Sources.
- Add or import local sources.
- Backup and restore the database.
- Verify production data.
- Cleanup test data after preview and confirmation.

## Pre-Service Checklist

1. Open MessageFlow.
2. Open the projection window and confirm it appears on the correct display.
3. Search `John 3:16`.
4. Project `John 3:16`.
5. Search `Faith Is The Substance 4`.
6. Project the selected sermon paragraph.
7. Test Previous and Next.
8. Create a fresh database backup from Admin Tools.

## Emergency Fallback

- Use the existing OpenLP setup if MessageFlow cannot be used.
- Restore the latest database backup from Admin Tools if data becomes inconsistent.
- Keep a known-good backup on an external drive before major imports or cleanup.

## Production Notes

- Admin Tools are separate from the normal service workflow.
- Test sources are hidden from normal operator views.
- Cleanup Test Data creates a backup before deleting any test source data.
- Do not import or cleanup during a live service unless absolutely necessary.
