## Included In v1.0.7

- Fast startup (< 3s main window display, non-blocking background initialization, no "Not Responding" freeze)
- Universal projection auto-fit across all content types (sermons, Bible, songs) with safe margins and zero overflow across 720p, 1080p, and 4K displays
- 5% micro-adjustments via A- / A+ buttons and 1-click Auto reset button
- Window placement and maximized state persistence across application sessions
- High DPI awareness (PerMonitorV2) via native app manifest
- ReadyToRun ahead-of-time compilation for instant cold startup
- 1,288 English (1,203 Brother Branham + 85 Brother Frank), 384 French, and 622 Swahili sermons and publications
- Bibles: KJV, Louis Segond (LSG), SWHULB
- 357 English songs, 499 French hymns with verse/chorus interleaving, 281 Swahili hymns

## Release Rules

- Keep MessageFlow Media free.
- Do not sell the software or bundled content.
- Attach installers to GitHub Releases instead of committing large installer executables into normal git history.
