1. Project structure

Solution: MessageFlow.sln

Projects in the solution:

- src/MessageFlow.App/MessageFlow.App.csproj
  Role: The WPF desktop application. This is the main user interface for searching content, selecting paragraphs, projecting text, managing favorites and history, managing content sources, and backing up/restoring the local database.
  Target: net10.0-windows
  Notes: Uses WPF and references Core, Data, Importer, and Search.

- src/MessageFlow.Core/MessageFlow.Core.csproj
  Role: Domain model and abstraction layer. It defines the main entities such as Author, Sermon, SermonParagraph, ImportLog, FavoriteParagraph, ProjectionHistory, and ContentSource. It also defines repository/search abstractions.
  Target: net10.0

- src/MessageFlow.Data/MessageFlow.Data.csproj
  Role: SQLite and Entity Framework Core infrastructure. It contains MessageFlowDbContext, migrations, default database path logic, database repair/index rebuilding logic, and repository registration.
  Target: net10.0
  Packages: Microsoft.EntityFrameworkCore.Sqlite, Microsoft.EntityFrameworkCore.Design, SQLitePCLRaw.bundle_e_sqlite3.

- src/MessageFlow.Importer/MessageFlow.Importer.csproj
  Role: Console importer and shared import logic for local PDF files. It extracts PDF text with PdfPig, parses metadata, splits paragraphs, writes sermons/paragraphs/import logs, and also exposes a console search command.
  Target: net10.0
  Packages: UglyToad.PdfPig, Microsoft.Extensions.Hosting.

- src/MessageFlow.Search/MessageFlow.Search.csproj
  Role: Search service. It queries sermons and sermon paragraphs through SQLite SQL, uses FTS5 when available, falls back to LIKE matching, and supports filters such as author, source, year, title/code, keyword, and paragraph number.
  Target: net10.0

No other projects are currently listed in the solution.

2. Current database structure

Database path:
database/messageflow.db

EF Core entities exposed by MessageFlowDbContext:

- Authors
  Stores content authors. Current model fields include Id, FullName, DisplayName, Description, and related Sermons.
  Seeded author: William Marrion Branham / Brother Branham.

- ContentSources
  Stores registered local source folders and source types. Fields include Name, DisplayName, SourceType, Description, LocalFolderPath, and CreatedAt.
  Seeded source: Brother Branham sermon PDF collection at D:\Br William Marrion Branham\PDF.

- Sermons
  Stores one imported document per local PDF. Despite the name "Sermons", this table is currently also used for circular letters or other imported PDF documents.
  Fields include AuthorId, optional ContentSourceId, Title, SermonCode, Year, Date, Location, Language, SourceFilePath, and CreatedAt.

- SermonParagraphs
  Stores searchable/projectable paragraph records for each imported sermon/document.
  Fields include SermonId, ParagraphNumber, Text, SearchText, optional PageNumber, and CreatedAt.

- ImportLogs
  Stores import activity for local PDF files, including FilePath, Status, Message, and ImportedAt.

- FavoriteParagraphs
  Stores saved/favorite paragraph references. Each favorite points to one SermonParagraph and can hold optional Notes.

- ProjectionHistories
  Stores projected paragraph history. Each record points to one SermonParagraph and stores ProjectedAt plus the SearchQuery used when projected.

- No Bible entity classes exist.
- No DbSet for Bible books, chapters, verses, translations, or Bible search exists.
- No Bible migration/table was found.

Other database tables found in the live SQLite file:

  EF Core migration history.

  EF Core migration lock table.

- sqlite_sequence
  SQLite autoincrement bookkeeping.

- SermonParagraphSearch and its internal FTS tables
  Older FTS5 search table created by the AddSermonSearch migration.

- SermonParagraphsFts and its internal FTS tables
  Newer/current FTS5 search table created by AddSearchPerformanceIndexesAndFts. The current search service uses SermonParagraphsFts.

7. Working features

The following features are supported by the current code:

- Main WPF app shell
  MainWindow loads with a search bar, author/source/year filters, projection font-size selector, library tabs, paragraph results, selected paragraph preview, status bar, and projection status.

- Search
  Search text is debounced and searches automatically. It supports author, source, and year filters. It returns grouped sermon/document results and paragraph results.

- Quick Project Mode
  Pressing Enter while the search box has focus runs QuickProjectAsync. It searches and projects the best matching paragraph if one is found.

- Projection window
  Project opens one ProjectWindow and reuses/activates the existing projection window if already open. The window is borderless, black-background, centered text, and supports dynamic font fitting.

- Projection text paging
  Long text can be split into projection pages. The projection window shows a page indicator when needed.

- Next/Previous navigation
  Main window Previous/Next buttons move between paragraphs. The projection window Left/Right keys move through projection pages first, then adjacent paragraphs.

- Copy
  Copy copies the selected paragraph's full text to the clipboard.

- Favorites
  Add Favorite / Remove Favorite toggles the selected paragraph in FavoriteParagraphs. The Favorites tab loads saved paragraphs and can project a favorite by double-clicking.

- History
  Projection history records projected paragraphs. The History tab shows the newest items first and can project a history item by double-clicking.

- Backup Database
  Tools > Backup Database opens a save dialog and uses SQLite BackupDatabase to create a .db backup.

- Restore Database
  Tools > Restore Database asks for confirmation, creates a safety backup, copies the selected backup over the current database, deletes WAL/SHM files, runs database repair, and reloads app data.

- Open Backup Folder
  Opens the folder of the most recent backup made during the current app session.

- Source manager
  Tools > Sources lists content sources. Add New Source opens a dialog to register a local source with display name, source type, description, and folder path.

- Import preview / dry run
  Import Source scans local PDFs, compares them to already imported SourceFilePath values, and shows an Import Preview dialog before any database write happens.

- Source import for sermon PDF collections and circular letters
  Import Source is enabled for SermonPdfCollection and CircularLetter source types. It imports only new local PDFs and skips already imported file paths.

- Ewald Frank metadata repair
  Repair Source Metadata is limited to Ewald Frank sources and can repair circular-letter metadata.

- Search indexing/performance improvements
  The database has indexes and FTS5 support. The current search service uses SermonParagraphsFts and falls back to LIKE if FTS fails.

- Startup repair/logging
  App startup runs MessageFlowDatabaseRepair before showing MainWindow. Startup and unexpected errors are logged to logs/app-startup.log.

10. Current risks

- Database migration and repair risk
  Startup runs database repair before showing the UI. Careless changes to migrations, repair SQL, FTS triggers, or table names could affect startup and existing local data.

- Large database risk
  The live database is large and contains 193,772 paragraphs. Search, import, backup, and restore changes need to be tested with the real data volume.

- Search index risk
  The live database contains both old and current FTS tables. Changing search SQL or rebuilding indexes carelessly could break search or create stale index rows.

- Source import risk
  Import Source writes new sermons, paragraphs, import logs, authors, and search index data. Changes could duplicate documents, misassign authors, or damage metadata if SourceFilePath matching changes.

- Reset import risk
  The console importer supports --reset, which deletes imported sermons and paragraphs. Do not use it casually against the production database.

- Restore risk
  Restore replaces the current database. It does create a safety backup, but this remains a high-impact operation.

- Ewald Frank metadata risk
  The repair flow mutates document metadata and author assignment for selected Ewald sources. It should be tested on a copy before being used on a full production collection.

- Bible design risk
  Adding Bible support needs new tables, import rules, UI, and search behavior. Bolting Bible content into Sermons/SermonParagraphs without a clear design could create long-term confusion.

- UI complexity risk
  MainWindow already contains search, library tabs, paragraph results, selected paragraph actions, tools, status, and projection state. Adding Bible and Preview/Live mode will need careful layout planning.

- Projection workflow risk
  Projection currently sends content directly live. Adding Preview/Live mode later must avoid breaking Quick Project and direct projection behavior used by operators.

13. Final summary

Current project stage:
MessageFlow is a working MVP for local PDF sermon search and projection, centered around the imported Brother Branham sermon library.

What is stable:
The code clearly supports Brother Branham import/search/projection, paragraph navigation, favorites, projection history, source registration, import preview, backup/restore, and FTS-backed search.

What is not finished:
Ewald Frank support is partial and test-only. Bible support is not implemented. Preview/Live mode, OCR, production source editing, and a citation library are not implemented.

Best next step:
Stabilize the existing Brother Branham MVP first, then complete Ewald Frank support with tests and a production-ready source plan before adding Bible support.
